# KYC Verification System

## Description
A simple C program that verifies an identification number
against stored KYC records.

## Identification Types
- PAN Number
- Aadhar Number
- Aadhar ID
- Driving License
- Passport

## Concepts Used
- Arrays
- Variables
- Declaration statements
- Input and output
- Assignment statements
- Switch-case
- If-else
- For loop
- Flag variable
- Break statement
- Return statement

## Working
The user selects an identification type and enters an ID.
The program searches the corresponding stored records.
If a match is found, the individual is verified.
Otherwise, the individual is not verified.
